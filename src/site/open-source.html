Wayzerr's own code

The Wayzerr desktop app is released under the MIT licence. The source is at github.com/grigorsworks/wayzerr. The name and logo are not covered by that licence; see TRADEMARKS.md.

Third-party software

Wayzerr includes or downloads software from others under their own licences. The full list is in THIRD_PARTY_NOTICES.md. It includes Electron and Chromium, noVNC, PDF.js, Transformers.js, ONNX Runtime Web and the Whisper speech model, QEMU, and cloudflared. Licence texts for Chromium and its components are shipped with the app as LICENSES.chromium.html.
