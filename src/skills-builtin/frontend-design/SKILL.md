# Frontend design
- Decide the look before code: one idea (calm, bold, playful), one accent colour, two fonts at most, a spacing scale (4, 8, 16, 24, 40).
- Layout: strong hierarchy, generous white space, a clear main action per screen, works at phone width first.
- Avoid the generic look: no purple-gradient-on-white default, no emoji as icons, no stock card grids with identical boxes; use real content.
- Build as one clean file when small (HTML + CSS variables + a little JS). Dark and light colours as CSS variables. Keyboard focus visible, contrast at least 4.5:1, buttons are real buttons.
- Check it: open it in the browser tool or computer, look at a screenshot at phone and desktop width, fix overflow and clipped text, then show the user.
