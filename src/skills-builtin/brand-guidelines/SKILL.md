# Brand guidelines
Ask for (or find) logo, colours (hex), fonts, tone, dos and don'ts. Put them in CSS variables / document styles once, then use only those. Keep the logo clear of clutter and unstretched. Match the tone words in the copy. For Wayzerr: simple and professional, grey site background, no purple, black logo with the orange bot.
