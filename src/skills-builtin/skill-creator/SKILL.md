# Making a skill
A skill is a folder with `SKILL.md`: front matter (`name`, and a `description` that says WHAT it does and WHEN to use it, because that line decides when it is loaded) then the instructions: numbered steps, exact commands, the checks that prove it worked, pitfalls. Keep it under ~100 lines; put long reference in extra files next to it. Write it in the skills folder (use the skill tools the app gives you), then test it on a real task and tighten whatever the test showed was unclear.
