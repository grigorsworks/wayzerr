# Brainstorming first
1. Restate the goal in one sentence and ask the ONE question that changes the result most (not a list).
2. Offer 2 or 3 approaches, each with a one-line upside and downside, and say which you would pick and why.
3. When the user chooses, write a short plan: steps, what is done when, what could go wrong.
4. Only then build. If the request is already clear and small, skip this and just do it.
