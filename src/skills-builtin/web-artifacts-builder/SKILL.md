# Small web tools
One HTML file: inline CSS and JS, no build step, data in `localStorage` with try/catch. State in one object, render from state. Big touch targets, works on a phone, keyboard friendly. Test with the browser tool: click every control, try empty and extreme input. Hand over the file path and what it does.
