# Co-writing a document
1. Ask for purpose, reader, length, tone (one short message). 2. Propose an outline, get a yes. 3. Draft one section at a time, short and concrete, then ask what to change. 4. When all is drafted, read it as the reader: cut repetition, define terms, check numbers. 5. Deliver as the format they want (Word, PDF, Markdown) in the shared Files folder.
