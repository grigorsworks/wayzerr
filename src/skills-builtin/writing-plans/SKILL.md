# Writing plans
Write: goal, assumptions, steps in order (each small enough to finish and check in one go, with the file or tool it touches), how each step is verified, risks and how to undo. Keep it to one page. Ask the user to confirm only when a step is expensive, hard to undo or ambiguous.
