# Security

If you find a security problem in Wayzerr, please **do not open a public issue**. Email **hello@wayzerr.com** with what you found and how to reproduce it. We aim to reply within 5 working days and to fix confirmed problems promptly, and we will credit you if you like. If you act in good faith (no data theft, no harm to other users, no public disclosure before we have had a reasonable chance to fix it, and only testing your own accounts and computers), we will not take legal action against you. Our contact file is at https://wayzerr.com/.well-known/security.txt.

Good to know: the Mac and Windows builds are not code-signed yet, so the operating system shows a warning the first time you open them (see the download page on https://wayzerr.com). Bots can browse the web, use connected apps and run programs inside a virtual machine, so please read `src/ai.js`, `src/computer.js` and `src/mymac.js` before trusting a modified build.
