# Security

If you find a security problem in Wayzerr, please **do not open a public issue**. Email **hello@wayzerr.com** with what you found and how to reproduce it. We will answer as soon as we can and credit you if you like.

Good to know: the Mac and Windows builds are not code-signed yet, so the operating system shows a warning the first time you open them (see the download page on https://wayzerr.com). Bots can browse the web, use connected apps and run programs inside a virtual machine, so please read `src/ai.js`, `src/computer.js` and `src/mymac.js` before trusting a modified build.
